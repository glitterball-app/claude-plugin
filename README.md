# Glitterball for Claude Code

Interactive video walkthroughs over your live prototype, shared by link. Add the skill to Claude Code, Cursor, Codex or any agent that reads skills:

```
npx skills add https://github.com/glitterball-app/claude-plugin --skill glitterball
```

Or install it as a Claude Code plugin:

```
/plugin marketplace add glitterball-app/claude-plugin
/plugin install glitterball@glitterball
```

Then ask Claude to add Glitterball to your prototype, or run `/glitterball`. More at https://www.glitterball.dev.
